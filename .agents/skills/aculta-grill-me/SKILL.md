# Esclarecimento dirigido, por demanda

1. Confira codigo, ADRs e contexto antes de perguntar. O pedido de implementacao ja autoriza desenvolvimento comum dentro do escopo.
2. Escolha e justifique autonomamente detalhes tecnicos reversiveis; nao exija um "sim" ritual.
3. Se faltar decisao real do responsavel (produto, dados institucionais, alteracao irreversivel), faca uma pergunta objetiva por vez, com consequencia clara.
4. Execute antes a parte independente. Se a operacao for R3, aguarde autorizacao explicita para a operacao sensivel; ausencia de resposta nao autoriza executar.
