# Padrão anterior de navegador (arquivado)

Até 2026-11-05, o projeto usava Firefox ESR do sistema via geckodriver/WebDriver,
com `DISPLAY=:0` para aceite visual e Firefox headless em alguns gates repetitivos.

Esse procedimento foi substituído pelo padrão único Playwright com Firefox próprio.
O arquivo é apenas registro histórico; não é instrução operacional vigente.
