# Projetos de referência para estudo

## Localização

Projetos externos baixados para estudo, análise ou extração de padrões e
funções ficam em:

```text
/home/piradopirata/aculta-tools/
```

Essa pasta é um acervo de referências separado do checkout do site ACULTA. Não
armazene clones, arquivos compactados ou cópias desses projetos em `web/`, no
repositório do site ou em diretórios temporários.

## Procedimento

1. Antes de baixar, confira se a referência já existe no acervo e reutilize-a
   quando corresponder ao projeto e à versão necessários.
2. Dê a cada projeto seu próprio subdiretório. Registre em um README local a
   origem (URL), versão, tag ou commit e a finalidade da análise; não inclua
   credenciais ou dados privados.
3. Preserve o material baixado como referência. Faça alterações de integração
   no checkout ACULTA, adaptando o código às suas convenções e APIs.
4. Confira a licença e os requisitos de atribuição antes de copiar ou adaptar
   código. Registre a origem junto à implementação quando aplicável.
5. Se a pasta não estiver acessível ou gravável, siga o mecanismo de aprovação
   do ambiente para obter acesso. Não use outro caminho para contornar essa
   restrição.

## Limites

O acervo não faz parte do repositório ACULTA e seu conteúdo não deve ser
versionado junto com o site. A regra vale tanto quando o agente decide baixar
um projeto para estudar quanto quando o responsável solicita a análise de um
projeto externo.
