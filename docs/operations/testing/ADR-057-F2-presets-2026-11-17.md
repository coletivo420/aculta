## APIs de composição encontradas

- UI Patterns Library cataloga SDCs e stories individuais; na inspeção do
  Composer, Config Sync e módulos ativos não foi encontrada uma entidade para
  salvar uma composição arbitrária de vários SDCs como preset entre sites.
- UI Patterns Views persiste componente, props, slots e fontes no YAML da
  View. Layout Builder/UI Patterns persiste layouts e configurações em
  `core.entity_view_display` ou configuração do bloco.
- Composições emitidas por Form API/PHP são versionadas junto ao módulo/tema,
  mas não são editáveis/exportadas como configuração editorial.
- Portanto, as composições Views são os candidatos nativos mais fortes para
  presets reproduzíveis; Account e Links precisam permanecer classificados
  como adaptadores de código até existir uma API instalada que satisfaça os
  requisitos sem criar catálogo paralelo ou duplicar conteúdo.

## Controles e lacunas para fechar F2

- **Versão/export:** View, display e placement somente em `config/sync`; render
  arrays/SDCs somente em código versionado. Não criar valores de configuração
  inventados nem editar conteúdo para fabricar exemplos.
- **Permissões:** não alterar grants nesta etapa. Antes de permitir edição de
  preset, verificar permissões nativas do consumidor (Views, Layout Builder,
  bloco e conteúdo) com papéis autorizados e anônimos.
- **Rollback:** restaurar apenas os YAMLs envolvidos e reimportar em operação
  separada autorizada; para composição em código, reverter o commit. Preservar
  as consultas, ordenação, pager, render arrays, acesso e cache.
- **Revisão:** responsável do módulo owner + revisão visual/editorial; verificar
  claro/escuro, teclado, 320 px e conteúdo real permitido. Nenhuma captura ou
  configuração Runtime foi alterada nesta fase.
- **Próximo passo:** confirmar se os presets F2 podem ser representados por
  View/display/placement já suportado. Só então criar as configurações
  editoriais nos consumidores escolhidos e cobrir persistência, permissões e
  rollback. Sem isso, manter F2 parcial.
