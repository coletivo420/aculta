# ADR-057 — evidências F3 / UI Icons (2026-11-17)

## Estado

F3 segue **EM ANDAMENTO**. Esta entrega completa a configuração do seletor
UI Icons Menu para os menus `main`, `account` e `admin`, sem alterar permissões
ou adicionar ícones aos links existentes. A configuração continua em Config
Sync; nenhuma importação foi executada no Runtime.

## Mudança

- `system.menu.admin` agora usa o Picker com resultado em grade, packs
  `aculta_phosphor_regular`, `aculta_phosphor_duotone` e `aculta_brocolis`,
  ícone opcional e escolha de posição habilitada. O Fluent Emoji não é
  disponibilizado como pack de ícones de navegação.
- O teste `UiIconsPackTest` verifica habilitação dos módulos UI Icons,
  descoberta dos packs locais e configuração equivalente dos três menus.
  Nenhum ícone decorativo foi convertido em conteúdo sem nome acessível e
  nenhuma permissão foi concedida.
- O SDC `icon` agora aceita `label` opcional: sem label continua `aria-hidden`,
  e com label usa `role="img"` e `aria-label`. A story informativa e o teste
  focal cobrem os dois contratos; os usos atuais sem label mantêm o markup
  decorativo.
- A API upstream 2.1.0 confirma que UI Icons Menu armazena o seletor e os packs
  permitidos como third-party settings do menu e aplica os controles aos links
  `menu_link_content`. A tela de edição continua sujeita à permissão Core
  `administer menu`.

## Pendências F3

- Testar edição, gravação e renderização de um link de menu com ícone em cada
  menu permitido; confirmar ícone decorativo versus nome acessível para usos
  informativos. Isso depende de sessão autenticada e revisão visual.
- Homologar UI Icons Patterns, Picker, Popover e Fields em consumidores reais,
  incluindo persistência/exportação e permissões por papel.
- Homologar UI Styles Page por tema/região, saída de classes e prévia; avaliar
  formatos CKEditor 5 e Entity Status com conteúdo real e filtros.
- Revisar o Config Sync contra Runtime em operação autorizada. Não classificar
  F3 como concluída enquanto as provas funcionais acima estiverem pendentes.
