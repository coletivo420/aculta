- **Escopo:** fundação reutilizável de preset para o SDC `layout-grid`, sem declarar iniciada ou concluída a fase P03, que depende de P01/P02.
- **Contrato:** adicionada a prop `preset` (`custom`, `cards-compact`, `cards-standard`, `cards-wide`). Os presets nomeados aplicam larguras mínimas de 12rem, 16rem e 20rem e zeram o limite explícito de colunas; `custom` preserva `min_item_width`/`max_columns` e é o default, mantendo consumidores existentes sem mudança de comportamento.

## Inspeção da API nativa para persistência (2026-11-17)

- Composer lock local identifica UI Patterns `2.0.x-dev`, commit `a7e9c28c522a5b0c8b71c731cab5482d60164e1e`; `ui_patterns_field` instalado declara compatibilidade com Core `^10.6 || ^11.3 || ^12`. Não há dependência nova nesta inspeção.
- A API `ui_patterns_source` já fornece FieldType (`SourceValueItem`), widget `ui_patterns_source` para editar a configuração de source/slots, formatter `ui_patterns_source` e lista multivalorada. O formatter usa a árvore persistida para renderizar a composição; não é necessário um engine proprietário para armazenar/renderizar essa árvore.
- O FieldType persiste `source_id`, a árvore serializada `source`, `node_id` e `third_party_settings`; ao atribuir valores, a API garante IDs estáveis para nós da árvore. A API, portanto, oferece persistência de conteúdo e edição via Field API, mas isso não equivale a um catálogo compartilhado de presets nem a configuração exportável de presets reutilizáveis.
- Há configuração `synchronized_translation` (default `TRUE`): o contrato é compartilhar estrutura entre traduções e manter valores textuais traduzíveis; com `FALSE`, as árvores podem divergir. A suíte upstream contém cenários Kernel de tradução sincronizada e independente. Isso é evidência de comportamento upstream, não validação ACULTA de revisão, rollback, permissões, cache ou export/import de configuração.
- **Decisão técnica provisória:** preservar UI Patterns Field como candidato para composições pertencentes ao conteúdo/domínio e revisionadas pela entidade owner. O catálogo de presets deve continuar separado e reutilizável por configuração exportável; composição específica não deve migrar conteúdo editorial para uma configuração global. Antes de adotar um campo em qualquer bundle, ainda falta testar o fluxo ACULTA com revisão, tradução, cache, acesso e export/import em banco de teste.
- **Gates desta inspeção:** leitura dos arquivos instalados e `composer show --locked` — PASS; nenhuma alteração de implementação, configuração Sync ou Runtime. Testes Kernel upstream não foram executados nesta inspeção (DEFERRED); a evidência citada vem dos arquivos de teste instalados.
