# ACULTA420 Storybook

Este catálogo documenta os componentes reais do tema Drupal `aculta420`. As stories são renderizadas pelo Drupal Storybook, usando os componentes Single Directory Components (SDC) e o tema ACULTA420; o Storybook não substitui o Drupal nem seus dados, permissões ou formulários.

## Navegação

- **Sistema visual**: tokens semânticos, Bootstrap 5, modos de cor e identidade.
- **Arquitetura**: fronteira Drupal Core/contrib → `aculta_portal` → contrato neutro → ACULTA420.
- **Acessibilidade**: requisitos de teclado, semântica, contraste e movimento.
- **Desenvolvimento**: criação de componentes, stories, hooks e revisão.
- **IA e agentes**: contexto mínimo obrigatório, limites e fluxo de trabalho.
- **Componentes**: stories SDC agrupadas por domínio.

## Executar localmente

1. Instale as dependências JS: `cd storybook && npm ci`.
2. Habilite o módulo Drupal Storybook apenas no site de desenvolvimento e conceda `render storybook stories` ao papel Administrator.
3. Gere os arquivos JSON das stories com Drush usando o URI local correto: `cd storybook && npm run stories:compile -- --uri=https://URI-DO-AMBIENTE`.
4. Inicie `npm run storybook` e acesse `http://localhost:6006`.

O Drupal deve estar acessível e a sessão autenticada como administrador no navegador para renderizar stories. Não habilite `storybook.development`; esse modo ignora a verificação de permissão. Não habilite CORS com `*` nem conceda renderização anônima. Configure CORS somente no serviço de desenvolvimento e para a origem exata do Storybook local.

## Fonte de verdade

Os contratos executáveis continuam nos arquivos `components/**/**.component.yml` e `components/**/*.twig`; cada `*.stories.twig` renderiza o SDC real. A documentação normativa para agentes também permanece nos Markdown em `web/themes/custom/aculta420/docs/` e nas instruções do repositório. Esta interface organiza e apresenta as regras e os exemplos visuais.
