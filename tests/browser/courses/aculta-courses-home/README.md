# Raiz pública do domínio de cursos

Smoke visual somente leitura da raiz pública do `site_key` `courses`. A origem
vem da variável `COURSES_HOST`, preenchida com o alias do Runtime de desenvolvimento
durante a execução. O teste não autentica nem altera conteúdo.

As páginas autenticadas de cursos continuam cobertas pelas frentes LMS e GanjaLab.
