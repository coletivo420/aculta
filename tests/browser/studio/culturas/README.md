# Studio · Culturas

Suite Culturas (`/culturas`, purpose `eventos`). Contém o dashboard, o runtime, o zoom de formulários, a matriz de navegador e o gate rápido de Culturas. A suite completa do Studio está no README de `../geral/`.

Ambiente: `ACULTA_BROWSER_ENV=desenvolvimento` ou `local`. Artefatos em `$SUITE_OUT`.
