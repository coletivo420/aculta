# Studio · Marley

Suite Marley (`/marley`, purpose `account`). O teste visual de navegação e as abas está em `visual.mjs`. A suite completa, com ambiente, variáveis e critérios, está no README de `../geral/`.

Ambiente: `ACULTA_BROWSER_ENV=desenvolvimento` ou `local`, com `ACULTA_SITE_ORIGIN` ou a URL do `/marley`. Artefatos em `$SUITE_OUT`.
