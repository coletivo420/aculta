# Raiz pública do domínio de apoio

Smoke visual somente leitura da raiz pública do `site_key` `support`. A origem
vem da variável `SUPPORT_HOST`, preenchida com o alias do Runtime de desenvolvimento
durante a execução. O teste não autentica nem altera conteúdo.

O fluxo de FAQ em MAIN continua coberto pela frente `aculta-faq` e pelo seu
script próprio.
