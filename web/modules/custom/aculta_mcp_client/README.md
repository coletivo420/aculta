# Compatibilidade do ID antigo do ACULTA MCP

`aculta_mcp_client` foi substituído funcionalmente por [`aculta_mcp`](../aculta_mcp/README.md), o módulo dono do servidor MCP, dos clientes de documentação, Resources, Prompts e autenticação.

Esta extensão mínima permanece habilitada como shim para preservar o estado instalado e referências existentes. Ela não registra plugins nem serviços. Removê-la exige uma ordem separada de desinstalação.
