# Fórum — instruções locais

Herde as regras da raiz e do Portal. Para trabalho no Fórum, consulte `README.md` e somente as seções relevantes dos contratos locais.

- Preserve acesso por purpose, grants de tópico/post, Domain, moderação e revisões.
- Comments legados e posts revisionáveis coexistem durante a migração; não execute migração nem apague dados sem autorização.
- Confira dependências e efeitos em `aculta_user`, Messenger, Search API e `aculta_statistics` apenas quando o diff tocar essas integrações.
- Use os testes/gates pertinentes ao código alterado. Não assuma estado do Runtime a partir da documentação.
