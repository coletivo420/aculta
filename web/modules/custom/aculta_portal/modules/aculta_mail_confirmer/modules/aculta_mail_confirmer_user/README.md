# ACULTA Mail Confirmer User

Submódulo do `aculta_mail_confirmer`: confirma a troca de e-mail da conta e pode registrar confirmação de endereço no primeiro login ou no login por link de uso único. Não bloqueia o login: a conta ativa pode entrar, enquanto recursos protegidos pela política do Portal ficam indisponíveis até a confirmação. Consulte [política atual](../../../../../../../../docs/portal/EMAIL-CONFIRMATION-POLICY.md).
Configuração em `/painel-administrativo/aculta/confirmacao-de-email/usuario`. Origem e licença: `LICENSE.txt` do módulo principal.
