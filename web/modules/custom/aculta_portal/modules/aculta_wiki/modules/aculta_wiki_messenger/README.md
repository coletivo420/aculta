# ACULTA Wiki Messenger

Este módulo não contém consumidores, armazenamento, workers, rotas ou transporte. A integração ativa foi migrada para `aculta_messenger`; o produtor do evento permanece em `aculta_wiki`. O módulo oculto é uma identidade de compatibilidade para instalações que ainda o tenham habilitado até uma desinstalação operacional autorizada. Não habilitar em novas instalações.
