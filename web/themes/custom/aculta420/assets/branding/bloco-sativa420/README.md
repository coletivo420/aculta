# Bloco Sativa 420 — assets institucionais

As fontes fornecidas pelo responsável ficam em `source/`; derivados de distribuição em `web/`.
As imagens têm fundo escuro incorporado e não devem ser tratadas como logotipos transparentes. Nunca aplicar filtros de cor, cortar a arte ou deformar a proporção.

- Horizontal: original 2048×682; WebP 640, 960, 1280, 2048 px de largura.
- Quadrada: original 1024×1024; WebP 256, 512, 1024 px.
- Manifesto: `manifest.json` com dimensões, tamanho, SHA-256 e alfa.
- Uso: cards, páginas de projeto, editorial e peças promocionais. Sem cabeçalho global e sem Domain purpose próprio.
- Acessibilidade: alt contextual, por exemplo `Bloco Sativa 420 — arte com participantes mascarados, folhagens e as cores verde, amarelo e vermelho`; quando imagem decorativa adjacente a texto equivalente, `alt=""`.
- Conteúdo editorial futuro: Drupal Media/File API com Image Styles e Responsive Image; não arquivar capas de eventos ou fotografias dinâmicas aqui.
- Fonte/autoria: recebida nesta conversa; metadados de autoria, licença e créditos ainda precisam ser formalmente confirmados antes da publicação.
- Para reproduzir: não regenerar automaticamente as fontes nem variantes existentes sem defeito objetivo. Atualizar o manifesto se qualquer byte mudar.
