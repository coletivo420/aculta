# author-card

Cartão visual para a identidade já autorizada pelo `aculta_user`. O adaptador
`templates/aculta-user-author-card.html.twig` mapeia os dados neutros e conserva
os render arrays de avatar e ações nos slots. O componente não carrega usuário,
Profile, foto nem decide visibilidade; nunca gera iniciais.

Story: `author-card.default.story.yml`.
