# Breadcrumb

Trilha visual baseada no breadcrumb público da V1: links editoriais sublinhados,
separador `/` e página atual sem link. O template Drupal mantém a montagem dos
itens e fornece o markup como slot, sem transferir regra de rota ao componente.

O layout começa em uma coluna de leitura fluida e quebra itens longos sem
estender a página. O contraste dos links usa tokens próprios do modo explícito.
