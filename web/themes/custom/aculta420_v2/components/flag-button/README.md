# Botão de marcação (seguir/salvar)

Botão de alternância de um tópico do Fórum, com ícone Phosphor. Usado pelos flags `flag_seguir_topico` e `flag_salvar_topico` via templates `flag--<id>.html.twig`.

- `pressed` reflete `action == 'unflag'` do Flag (já marcado).
- Stories: `default` (não marcado) e `pressed` (marcado).
