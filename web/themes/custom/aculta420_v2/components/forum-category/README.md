# Categoria do Fórum

Card da View pública e do bloco de categorias da landing, com título,
hierarquia, descrição e contagem entregues como slots renderizados pelo Drupal.

- Schema sem props de regra de negócio; quatro slots de conteúdo autorizado.
- Story: `forum-category.default.story.yml`.
- CSS mobile-first, sem classes de framework.
- Consumidores: lista pública de categorias e bloco de categorias da landing.
