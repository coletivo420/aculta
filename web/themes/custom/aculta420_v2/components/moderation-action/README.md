# Ação de moderação

Link de ação administrativa com ícone Phosphor. Usado pelos controles de moderação do Fórum (tópicos e comentários).

- Ícone: pacote Phosphor em `assets/icons/phosphor`, via SDC `icon` (`duotone` por padrão, `regular` quando só existir esse peso).
- Tom `danger` para excluir e remover; `neutral` para o restante.
- Stories: `default` (neutro) e `danger` (perigo).
