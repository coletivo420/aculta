# Botão de envio de moderação

Botão de envio (Form API) dos controles administrativos de comentário. Recebe o ícone Phosphor pela propriedade `#moderation_icon` do elemento; o override `input--submit--moderation` aplica o componente quando a propriedade existe.

- Tom `danger` para remover e excluir; `neutral` para despublicar, republicar e restaurar.
- Stories: `default` (neutro) e `danger` (perigo).
