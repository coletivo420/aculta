# revista-listing

Cabeçalho e grade de publicações da View `revista_sessoes:page_revista`.
Recebe a saída renderizada da View em um slot; não consulta conteúdo nem
reordena o DOM.

O título editorial é o H1 da página; o título genérico do Drupal é ocultado
somente enquanto esta listagem está presente.

Story: `revista-listing.default.story.yml`.
