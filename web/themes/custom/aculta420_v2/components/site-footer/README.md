# Site footer

Apresenta a região Drupal `footer` como rodapé institucional responsivo. O slot
`content` recebe o render array da região sem transferir sua construção,
permissões ou cacheabilidade para o tema.

O grid começa em uma coluna e amplia para duas e quatro colunas conforme o
conteúdo e o viewport. A identidade usa tokens semânticos compartilhados com o
tema, sem depender das classes ou da grade do Bootstrap.
