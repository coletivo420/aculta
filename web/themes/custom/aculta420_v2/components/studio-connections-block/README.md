# Studio Connections Block (`aculta420_v2:studio-connections-block`)

Bloco de conexões para o Studio Dashboard:
- Exibe o título "CONEXÕES".
- No estado vazio: exibe "Você ainda não tem conexões" e o botão "Encontrar conexões".
- Com conexões: exibe as primeiras conexões aceitas com avatar circular do ACULTA, nome e link "Ver perfil", e o botão/link "Ver todas".
- Faixa superior `--studio-stripe` e cantos `--radius-lg`.
