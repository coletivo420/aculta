# Studio Connections Page (`aculta420_v2:studio-connections-page`)

Página de gerenciamento de conexões no Studio (`/conta/conexoes`):
- Duas caixas: "Suas conexões" (filtro, lista com avatar, nome, link para perfil, mensagem e menu ⋯) e "Buscar novas conexões" (busca a partir de 3 caracteres, resultados com "Adicionar", "Pendente" ou "Conectado").
- No celular, as caixas empilham verticalmente.
- Carregamento progressivo ao rolar até o fim da lista.
