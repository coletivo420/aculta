# Item de denúncia (educador)

Linha da fila do Ganjalab Educador. Mostra um conteúdo denunciado de uma discussão de curso,
a contagem de denúncias pendentes, a última data e o link de análise.

- Usado pelo workspace do educador (`/ganjalab/educador/denuncias`), nunca pelo Fórum público.
- Textos e datas chegam prontos do servidor; o componente não decide permissão.
- Stories: `default` e `many`.
