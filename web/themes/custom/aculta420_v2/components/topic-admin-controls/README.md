# topic-admin-controls

Conteúdo do popup de moderação do tópico. Espelha `comment-admin-controls`: situação
somente leitura, ações autorizadas e registro. O registro vem das decisões do
`aculta_cgu` sobre o alvo (tipo node, id do tópico). O SDC não decide acesso; as
ações chegam já filtradas pela permissão.
